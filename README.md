🍽️ Restaurant Website Project

A modern and responsive restaurant website built using HTML, CSS, and JavaScript 🚀.
This project showcases a complete multi-page restaurant web application with an attractive UI, delicious food menu sections, reservation/contact forms, and smooth navigation.

✨ Features
📱 Responsive design for mobile, tablet, and desktop
🏠 Home page with hero section and call-to-action
🍕 Menu page with categorized food items
👨‍🍳 About Us section with restaurant details
🖼️ Gallery section for food and restaurant images
📞 Contact page with reservation/contact form
⚡ Smooth scrolling and interactive UI
🎨 Clean and modern layout
